## Как это работает

- Курс задаётся вручную в диапазоне от 20 до 80. Значение применяется, когда поле теряет фокус
- Каждые 15 секунд приложение заново читает `data.json` и одновременно ставит новый случайный курс из того же диапазона. То же самое делает кнопка рядом с таймером. Запрос идёт с `cache: "no-store"`, чтобы браузер не отдавал старый файл
- В корзину товар добавляется по одному, удаляется кнопкой. В строке показана сумма позиции (цена × количество), снизу  общая сумма
- Кнопка «Купить» выключена, если остаток равен нулю. Если в новом ответе остаток стал меньше, чем уже лежит в корзине, количество уменьшается до него. Если товара больше нет или остаток стал нулевым, позиция из корзины убирается


## Решение

В своих решениях я использовал `useSharedComposable` вместо `pinia`, так как проект не большой и я не видел в нем смысла

### Composables
- Разделил весь функционал на `composable` и выполняю всю логику там
- `useGetData` - отвечает за прием данных и вывод в рабочий вид. Так же там собираются все `products` для дальнейшего использования в сравнении цен у товаров
- `useCachePrice` - отвечает за прием товаров и составлении мапы {id: price}, чтобы точечно регулировать спад или повышение курса
- `useCart` - работа с корзиной (добавление\удаление\увеличение кол-ва товаров)
- `useStore` - общий компоузебл с использованием `useSharedComposable`, для общих стейтов\методов и доступности во всем проекте 


### Helpers

- Сделал для удобства общий хэлпер `_formatPrice`, чтобы добавлять туда логику с форматированием цены


### Types

- Типизация для данных с `data.json`,товаров,товаров в корзине
- Для общих структур и composable использовал явную типизацию TypeScript.

## Ограничения

1. Копейки отдельно не обрабатываются. Суммы и сравнение считаются как цена × курс без округления до двух знаков. `Intl` на экране показывает две цифры после запятой
2. Если цена не изменилась, остаётся подсветка прошлого изменения. Рамка сбрасывается только когда рублёвая цена реально стала больше или меньше
3. Отдельного состояния «ноль штук в корзине» нет. Если количество в поле доходит до нуля, позиция удаляется
4. Решение специально оставил небольшим, без лишних слоев, сторов и оптимизаций. Для текущего объёма данных они не меняют поведение, а только удлиняют код (например использовать new Map вместо линейного .find)
